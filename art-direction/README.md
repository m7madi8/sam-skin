# SAM SKIN — Art Direction Carousel

Instagram-format slides at **1080 × 1350 px**.

## Files

| File | Content |
|------|---------|
| `carousel.html` | Full deck (slides 01–06) |
| `slides-05-06.css` | Art direction for slides **05** and **06** only |
| `slides-locked.css` | Frozen styling for slides **01–04** placeholders |

## Export

1. Serve the repo root (e.g. `py -m http.server` from `sam-skin/`).
2. Open `art-direction/carousel.html` at **100% zoom**.
3. Capture `#slide-05` and `#slide-06` at 1080×1350 (browser extension or OS crop).

## Slide 05 — concept chosen

**“Monument + Index + Interface”** (vs. flat four-card grid, vs. dialog-only hero): ensemble photography dominant, vertical product index with real pack shots, built `.col__quartet` preview in a browser chrome, and an enlarged static `#prodDlg` for Pure Form — only **See it in the ritual** (no commerce).

## Slide 06 — concept chosen

**“Campaign close + collection inset”** (vs. generic thank-you, vs. fake contact): full-bleed `1794147832524.jpg`, monochrome type block, small collection inset — portfolio statement, not a contact card.

## Slides 01–04

Placeholders only. Swap in your approved slides by replacing the `slide--01` … `slide--04` blocks in `carousel.html` **without** changing `slides-05-06.css`.
